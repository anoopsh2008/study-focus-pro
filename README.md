# 🎓 StudyFocus Pro
​Smart Study, Healthy Breaks & Safe Rewards System > Empowering students to conquer study goals without dopamine burnout while keeping parents in the loop.
​Lead Developer & Creator: Anoop Sharma
​🌟 Overview
​StudyFocus Pro is a modern, student-friendly web application designed by Anoop Sharma to build sustainable study habits. It combines flexible focus timers, strict website/app blocking during study hours, wholesome curated break reels, and rewarding milestone incentives (10%–15% discounts).
​✨ Key Features
​⏱️ Flexible Focus Timer & Custom Capacity:
​Choose from pre-set focus blocks (25m, 45m, 60m) or set a custom minute duration tailored to your daily study capacity.
​🛡️ Active Shield & Restricted App Blocker:
​Blocks distractive websites and apps (Instagram, YouTube Shorts, Snapchat, Netflix, Discord) during study sessions.
​Triggers warning alerts if unauthorized apps or browsing are attempted.
​🎥 Safe Break Reels (No Dopamine Traps):
​After completing a focus block, enjoy a 10-15 minute break featuring wholesome, educational reels (Study tips, sports & fitness, current affairs, and relaxation ambiance). No toxic scrolling or sensitive content!
​👨‍👩‍👧 Parent Portal & Automated Alerts:
​Keeps parents informed with simulated instant notifications and activity logs if a student is inactive or skips study mode.
​🎁 Rewards & Coupon Milestones:
​Complete your daily target of 4 focus sessions to unlock exclusive 10%–15% discount coupons for partner edtech platforms, stationery, and skill courses!
​🚀 Tech Stack
​Frontend: HTML5, Tailwind CSS, JavaScript (ES6+)
​Icons & Fonts: FontAwesome 6, Google Fonts (Plus Jakarta Sans)
​Architecture: Single-File Application (Zero complex build setup required)
​💡 How to Run Locally
​Clone or download this repository.
​Open the StudyFocusApp.html file in any modern web browser (Chrome, Firefox, Edge, Safari).
​Start studying and collecting rewards!
